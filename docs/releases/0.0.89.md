# pain001-sdk-cpp 0.0.89

A maintenance release of the C++ client, in lockstep with the pain001
suite's 0.0.89. The release workflow reads the Highlights below and
adds the pull requests, checksums and changelog link.

## Highlights ⭐️

* **In lockstep with pain001 0.0.89**: CI runs the vendored conformance kit against `pain001 serve` 0.0.89, and `kSdkVersion` and the `User-Agent` say 0.0.89.
* **Every release asset in the checksums**: the release notes' Checksums block now lists `SHA256SUMS` itself, which the 0.0.88 notes left out.
