# pain001-sdk-cpp 0.0.90

A maintenance release of the C++ client, in lockstep with the pain001
suite's 0.0.90. The release workflow reads the Highlights below and
adds the pull requests, checksums and changelog link.

## Highlights ⭐️

* **In lockstep with pain001 0.0.90**: CI runs the vendored conformance kit against `pain001 serve` 0.0.90, and `kSdkVersion` and the `User-Agent` say 0.0.90.
* **Tested against a server without the first-request race**: core 0.0.90 fixes a race in `lazy_module` that made a freshly started `pain001 serve` answer its first parallel requests with HTTP 500.
