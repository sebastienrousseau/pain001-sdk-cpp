# pain001-sdk-cpp 0.0.88

The first tagged release of the C++ client, in lockstep with the
pain001 suite's 0.0.88. The release workflow reads the Highlights below
and adds the pull requests, checksums and changelog link.

## Highlights ⭐️

* **A typed C++17 client for `pain001 serve`**: `health`, `validate`, `generate`, `check`, `faces`, `project_face` and a raw `request`, proven against the server by core's conformance kit in CI.
* **Opt-in retries for GET calls**: `ClientOptions::retry` takes a `RetryPolicy` with exponential backoff, jitter and `Retry-After`; POST is never retried.
* **`find_package(pain001_sdk 0.0.88 CONFIG)`**: `cmake --install` now exports `pain001::sdk`, and every release carries a source archive, a CycloneDX SBOM, SHA256SUMS and a provenance attestation.
* **An example for every method**: the library is tested to 100% of lines and branches, fuzzed on every pull request and benchmarked with Google Benchmark.
